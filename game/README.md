# 출근 저지 — MVP 프로토타입

`ideas/직장인_스트레스해소_게임.md` v2의 MVP 범위를 그대로 구현한 플레이 가능한 프로토타입.

## 실행

의존성·빌드·서버 없음. 파일을 브라우저로 열면 끝.

```
game/index.html
```

MG Commerce Flask 앱과 완전히 분리되어 있음 (`app.py`, `modules/`, `templates/`, `static/` 무관).

## 규칙

상대가 `집 → 이동 → 로비 → 엘리베이터 → 자리` 로 진행한다.
**09:00까지 자리에 앉히지 못하면 플레이어 승리.**

방해 카드로 각 구간에 지연(분)을 누적시킨다. 화면 우측의 **예상 도착 시각**이
09:00을 넘기면 저지 성공권.

## 구현된 MVP 범위

| 항목 | 상태 |
|---|---|
| 저지 1스테이지 (5구간 단일 경로) | ✅ |
| 방해 카드 5종 | ✅ |
| 직급 3종 × 부서 2종 | ✅ |
| 09:00 타이머 + 승패 판정 | ✅ |
| "오늘 누구 때문에 힘드셨나요?" 개인화 입력 | ✅ |
| 재시작 | ✅ |
| 보스키 (ESC → 엑셀 화면) | ✅ |

## 직급 × 부서

| 직급 | 특성 |
|---|---|
| 대리 | 지하철. 성실해서 지하철 방해 ×0.5 |
| 과장 | **차량** — 지하철 카드 무효, 교통 체증만 통함 |
| 부장 | 30분 일찍 출발 (07:10) — 막을 시간이 적음 |

| 부서 | 특성 |
|---|---|
| 영업부 | 외근 지시 한 장이면 즉시 이탈 = 즉시 승리 |
| 생산부 | 모든 지연 ×0.7, 외근 무효 |

## 카드

| 카드 | 기본 지연 | 횟수 | 조건 |
|---|---|---|---|
| 지하철 신호 고장 | 25분 | 1 | 지하철 이용자 전용 |
| 교통 체증 | 25분 | 1 | 차량 이용자 전용 |
| 엘리베이터 점검중 | 22분 | 1 | 엘리베이터 구간 |
| 카톡 폭탄 | 12분 | 3 | 현재 구간 어디서나 |
| 외근 지시 | 15분 | 1 | 영업부 = 즉시 승리 / 생산부 = 무효 |

## 밸런스 검증 (전 조합, Chromium 실측)

| 조합 | 무대응 도착 | 전 카드 사용 후 | 판정 |
|---|---|---|---|
| 영업부 대리 | 08:35 | — | 외근 한 장으로 즉시 승리 |
| 생산부 대리 | 08:35 | 09:23 | 승리 가능 |
| 영업부 과장 | 08:30 | — | 외근 한 장으로 즉시 승리 |
| 생산부 과장 | 08:30 | 09:27 | 승리 가능 |
| 영업부 부장 | 08:05 | — | 외근 한 장으로 즉시 승리 |
| **생산부 부장** | 08:05 | **09:02** | **최고 난도 — 여유 2분** |

무대응 시 전 조합 패배. JS 콘솔 에러 0건.

## 다음 단계 (재미 판정 후)
