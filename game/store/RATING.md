# 연령등급 — 문항 답안 초안

**등급은 제가 정할 수 없습니다.** 게임물관리위원회(GRAC)와 구글 플레이의
IARC 설문에 **이용자 본인이** 답해서 받는 것입니다. 이 문서는 그 설문에
사실대로 답하기 위한 자료입니다 — 게임에 실제로 무엇이 들어 있는지를
코드에서 확인해 적었습니다.

## 실제 내용 (코드 확인 결과)

| 항목 | 게임에 있는가 | 근거 |
|---|---|---|
| 폭력 | **있음 (비사실적·만화적)** | 도장·서류·사무집기로 사람을 「처리」합니다. 쓰러지는 연출이 있습니다 |
| 유혈 | **없음** | 파편·바닥 자국이 전부 커피(갈색)·소주(호박색)·음료(청록)입니다. 붉은 유혈 표현이 없습니다 |
| 신체 훼손 | 없음 | 쓰러지고 사라집니다 |
| 무기 | 없음 (실제 무기) | 도장·클립·서류·복사기 같은 사무용품뿐입니다 |
| **주류** | **있음** | 「회식조」 적이 술병을 들고 나오며 "한 잔만 더!", "2차 가자 2차", "딱 한 잔만!" 을 말합니다 |
| 담배 | 없음 | 코드에 표현 없음 |
| 약물 | 없음 | |
| 도박·사행성 | 없음 | 확률형 아이템, 베팅, 재화 구매가 없습니다 |
| 선정성 | 없음 | |
| 공포 | 없음 | |
| 비속어·차별 표현 | 없음 | 적 대사 103줄 전부 존댓말·직장 화법입니다 |
| 범죄·반사회성 | 없음 | |

## 예상 등급과 판단

- **주류 표현이 유일한 변수**입니다. 그 외에는 전체이용가 요건을 벗어나는
  것이 없습니다.
- 「회식조」는 직장 문화를 그리는 소재로 들어가 있고, 음주를 권하거나
  미화하지 않습니다. 다만 **설문에는 「주류 표현 있음」으로 답해야 합니다.**
  사실과 다르게 답하면 등급 재분류 대상이 됩니다.
- 이 답안대로면 **전체이용가 또는 12세이용가**가 나올 가능성이 높습니다.
  정확한 등급은 설문 제출 결과로만 확정됩니다.

## 결정이 필요한 것

전체이용가를 반드시 받아야 한다면, 「회식조」에서 술을 걷어내는 선택지가
있습니다 — 적 자체는 남기고 술병과 세 줄의 대사만 바꾸면 됩니다
(`E.drunk`, `SAY.drunk`, `DEBRIS.drunk`).
게임성에는 영향이 없지만, 「회식」이라는 소재가 이 게임의 공감 포인트 중
하나라 잃는 것도 있습니다. **이건 사업 판단이라 제가 정하지 않았습니다.**

## 국내 절차 메모

- 구글 플레이·원스토어에 올리는 게임물은 IARC 연계 설문으로 등급을 받습니다
  (자체등급분류사업자 경로).
- 청소년이용불가가 아닌 한 별도 GRAC 신청 없이 진행됩니다.
- 등급 표시 의무: 등급 분류를 받은 뒤 게임 내·스토어 페이지에 표시해야 합니다.
- 위 내용은 2026-09 기준 일반적인 절차이며, 제출 시점의 공식 안내를
  확인하시기 바랍니다.
