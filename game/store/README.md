# 스토어 제출 자산 — 「정시 퇴근」

전부 **실제 게임에서** 뽑았습니다. 합성하거나 꾸민 이미지가 없습니다.
게임을 고치면 아래 명령으로 다시 뽑으세요.

```bash
node game/store/make-icon.mjs      # 아이콘 5종
node game/store/make-shots.mjs     # 스크린샷 5종
node game/store/make-feature.mjs   # 피처 그래픽 (shot-4-wide.png 를 씁니다)
```

## 제출 전에 사람이 해야 하는 것

체크리스트입니다. **제가 대신 할 수 없는 것들**만 적었습니다.

- [ ] **개인정보처리방침을 URL로 게시** — 스토어가 접근 가능한 주소를 요구합니다.
      `PRIVACY.ko.md` 내용을 웹페이지로 올리고 그 주소를 등록하세요.
- [ ] **연령등급 설문 제출** — `RATING.md` 의 답안대로 답하세요.
      **「주류 표현 있음」에 반드시 예로 답해야 합니다**(회식조). 사실과
      다르게 답하면 재분류 대상입니다.
- [ ] **주류 표현을 뺄지 결정** — 전체이용가가 꼭 필요하면 `RATING.md` 의
      「결정이 필요한 것」을 보세요. 사업 판단이라 손대지 않았습니다.
- [ ] **개발자 계정·사업자 정보** — 구글 플레이 개발자 등록, 앱 서명 키 보관.
- [ ] **패키징** — 지금은 웹(PWA)입니다. 스토어에 올리려면 TWA(Trusted Web
      Activity)나 Capacitor 로 감싸야 합니다. 게임 자체는 오프라인으로
      완결돼 있어(외부 요청 0) 그대로 감싸면 됩니다.
- [ ] **스크린샷 최종 확인** — 구글 플레이는 세로 2장 이상을 요구합니다.
      지금 세로 4장 · 가로 1장이 있습니다.

## 확인된 사실 (설문에 그대로 쓰세요)

이 셋은 자동 검사로 매 배포 전에 확인합니다.

- **외부 네트워크 요청 0** — `game/test/cases/offline.mjs`
- **개인정보 수집 없음** — 로컬 저장소 네 개 키가 전부, 전송 없음
- **광고·인앱결제·계정 없음** — 해당 코드가 존재하지 않음

## 자동 검사

`node game/test/run.mjs store` — 51개 항목을 봅니다.
아이콘·스크린샷 크기, 매니페스트가 가리키는 파일의 실재와 크기,
서비스워커가 받으려는 파일의 실재, 그리고 **개인정보처리방침이 코드와
어긋나지 않는지**(광고·분석 SDK 부재, 저장 키가 전부 방침에 적혀 있는지)를
확인합니다. 저장 키를 새로 만들면 방침에도 적어야 검사가 통과합니다.
