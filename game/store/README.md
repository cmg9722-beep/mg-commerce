# 스토어 제출 자산 — 「정시 퇴근」

전부 **실제 게임에서** 뽑았습니다. 합성하거나 꾸민 이미지가 없습니다.
게임을 고치면 아래 명령으로 다시 뽑으세요.

```bash
node game/store/make-icon.mjs      # 아이콘 5종
node game/store/make-shots.mjs     # 스크린샷 5종
node game/store/make-feature.mjs   # 피처 그래픽 (shot-4-wide.png 를 씁니다)
```

## 이미 되어 있는 것

- **개인정보처리방침이 URL로 열립니다** — `https://…/game/privacy`
  (한/영, 브라우저 언어를 따릅니다. `#ko` · `#en` 으로 고정도 됩니다)
- **게임이 URL로 열립니다** — `https://…/game/rush.html`
- **PWA·오프라인** — 서비스워커가 등록되고, 네트워크를 끊어도 열립니다.
  `node game/test/run.mjs offline` 이 진짜 서버로 띄워 매번 확인합니다.
- **TWA 설정** — `twa/twa-manifest.json` 에 도메인·패키지명·아이콘이 채워져 있습니다.
- **assetlinks 경로** — `https://…/.well-known/assetlinks.json` 이 이미 열려 있습니다.
  지문만 채우면 됩니다.

## 제출 전에 사람이 해야 하는 것

**제가 대신 할 수 없는 것들**만 남겼습니다. 왜 못 하는지도 적었습니다.

- [ ] **앱 서명 키 만들기** — 한 번 정하면 앱의 평생 신원이라 소유자만
      만들어 보관해야 합니다. 남이 만든 키를 쓰면 그 사람이 내 앱 행세를
      할 수 있습니다. → `twa/README.md`
- [ ] **assetlinks 에 지문 채우기** — 위 키에서 나오는 값이라 키가 먼저입니다.
      안 채우면 앱 안에 브라우저 주소창이 보입니다.
- [ ] **`bubblewrap build` 로 .aab 만들기** — 키가 있어야 돌아갑니다.
- [ ] **연령등급 설문 제출** — 계정으로 하는 일이라 제가 못 합니다.
      `RATING.md` 답안대로 답하세요. **「주류 표현 있음」에 반드시 예**(회식조).
      사실과 다르게 답하면 재분류 대상입니다.
- [ ] **주류 표현을 뺄지 결정** — 전체이용가가 꼭 필요하면 `RATING.md` 의
      「결정이 필요한 것」을 보세요. 사업 판단이라 손대지 않았습니다.
- [ ] **구글 플레이 개발자 등록** — 계정·결제·사업자 정보.

## 확인된 사실 (설문에 그대로 쓰세요)

이 셋은 자동 검사로 매 배포 전에 확인합니다.

- **외부 네트워크 요청 0** — `game/test/cases/offline.mjs`
- **개인정보 수집 없음** — 로컬 저장소 네 개 키가 전부, 전송 없음
- **광고·인앱결제·계정 없음** — 해당 코드가 존재하지 않음

서비스워커가 받으려는 파일의 실재, 그리고 **개인정보처리방침이 코드와
어긋나지 않는지**(광고·분석 SDK 부재, 저장 키가 전부 방침에 적혀 있는지)를
확인합니다. 저장 키를 새로 만들면 방침에도 적어야 검사가 통과합니다.
