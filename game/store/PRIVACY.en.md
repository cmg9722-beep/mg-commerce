# Privacy Policy — On-Time Departure (정시 퇴근)

Last updated: 2026-09-13

## In one line

**This game collects no personal information.** Nothing is sent to any server.
All records stay on the player's own device.

## 1. Personal information collected

None.

No name, email, phone number, address, date of birth, gender, device
identifier, advertising identifier, or location. There are no accounts and no
sign-in.

## 2. What is stored on the device

The game writes only these four values to browser local storage. They never
leave the device.

| Key | Contents |
|---|---|
| `jeongsi.save.v1` | Career points, best records, days played, unlocked achievements, chosen role, clock-in rank and per-rank records, settings (sound, screen shake), and the sentence typed into "Your line" |
| `jeongsi.lang` | Chosen language (Korean / English) |
| `jeongsi.tut.v1` | Whether the first-run guide has been seen |
| `chulgeun.muted` | Whether sound is muted |

**About "Your line".** In Settings the player may type one sentence (max 40
characters); in-game bosses then say it. It is stored on the device only and is
never transmitted. Because it is a free-text field, **we recommend not entering
another person's real name or any sensitive content.** Left blank, the game
picks its own line.

To erase: **Settings → Erase records** in-game, or clear the app's stored data.
Uninstalling the app also removes it.

## 3. Network activity

The game makes no outbound requests while running. Every resource — fonts,
sounds, graphics — ships inside the app. This is verified before every release
by an automated check (`game/test/cases/offline.mjs`); the release is blocked if
any external request is found.

## 4. Third parties

None. No advertising networks, analytics, crash reporters, social sign-in, or
payment modules are used.

## 5. Children

Since no personal information is collected, none is collected from children.

## 6. Your rights

There is no personal data held to access, correct, or delete. Game records
stored on the device can be erased at any time by the player using the methods
in section 2.

## 7. Changes

If this policy changes, the date above is updated and the change is recorded in
this document.
