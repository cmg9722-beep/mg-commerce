정시 퇴근 (On-Time Departure) · 최종 수정 2026-09-13
한국어 English
이 게임은 개인정보를 수집하지 않습니다.
서버로 보내는 것이 아무것도 없습니다. 기록은 전부 이용자의 기기 안에만 남습니다.

1. 수집하는 개인정보

없습니다. 이름·이메일·전화번호·주소·생년월일·성별·기기식별자·광고식별자·위치정보를 포함해 어떤 개인정보도 수집하지 않습니다. 계정을 만들지 않으며 로그인이 없습니다.

2. 기기에 저장되는 것

게임은 브라우저의 로컬 저장소(localStorage)에만 다음 네 가지를 남깁니다. 이 값들은 이용자의 기기를 떠나지 않습니다.

저장 키담는 것
jeongsi.save.v1경력 점수, 최고 기록, 진행 일수, 해금한 업적, 고른 직군, 멀리 보는 목표 달성 여부, 동기 기록, 설정(소리·화면 흔들림), 「내 한 줄」에 적은 문장
jeongsi.lang고른 언어 (한국어 / English)
jeongsi.tut.v1첫 판 안내를 봤는지 여부
chulgeun.muted소리를 껐는지 여부
「내 한 줄」에 대하여. 설정에서 한 문장(최대 40자)을 직접 적을 수 있고, 게임 속 상사들이 그 문장을 말합니다. 이 문장 역시 기기에만 저장되며 전송되지 않습니다. 다만 이용자가 직접 적는 자유 입력란이므로, 다른 사람의 실명이나 민감한 내용은 적지 않기를 권합니다. 비워 두면 게임이 기본 문장을 씁니다.

지우는 방법: 게임 안 설정 → 기록 초기화. 또는 브라우저·앱의 저장 데이터 삭제. 앱을 삭제해도 함께 지워집니다.

3. 네트워크 통신

게임은 실행 중 외부로 어떤 요청도 보내지 않습니다. 글꼴·소리·그림을 포함한 모든 자원이 앱 안에 들어 있습니다. 이 사실은 자동 검사로 매 배포 전에 확인하며, 외부 요청이 하나라도 발견되면 배포가 중단됩니다.

4. 제3자 제공·위탁

없습니다. 광고 네트워크, 분석 도구(애널리틱스), 크래시 리포터, 소셜 로그인, 결제 모듈을 일절 사용하지 않습니다.

5. 아동의 개인정보

수집하는 개인정보가 없으므로 만 14세 미만 아동으로부터 수집하는 정보도 없습니다.

6. 이용자의 권리

수집·보관하는 개인정보가 없어 열람·정정·삭제를 요청할 대상이 없습니다. 기기에 저장된 게임 기록은 위 2항의 방법으로 이용자가 직접 언제든 지울 수 있습니다.

7. 방침의 변경

이 방침이 바뀌면 수정일을 갱신하고 변경 내용을 이 문서에 적습니다.

This game collects no personal information.
Nothing is sent to any server. All records stay on the player's own device.

1. Personal information collected

None. No name, email, phone number, address, date of birth, gender, device identifier, advertising identifier, or location. There are no accounts and no sign-in.

2. What is stored on the device

The game writes only these four values to browser local storage. They never leave the device.

KeyContents
jeongsi.save.v1Career points, best records, days played, unlocked achievements, chosen role, long-game goals reached, rival record, settings (sound, screen shake), and the sentence typed into "Your line"
jeongsi.langChosen language (Korean / English)
jeongsi.tut.v1Whether the first-run guide has been seen
chulgeun.mutedWhether sound is muted
About "Your line". In Settings the player may type one sentence (max 40 characters); in-game bosses then say it. It is stored on the device only and is never transmitted. Because it is a free-text field, we recommend not entering another person's real name or any sensitive content. Left blank, the game picks its own line.

To erase: Settings → Erase records in-game, or clear the app's stored data. Uninstalling the app also removes it.

3. Network activity

The game makes no outbound requests while running. Every resource — fonts, sounds, graphics — ships inside the app. This is verified before every release by an automated check; the release is blocked if any external request is found.

4. Third parties

None. No advertising networks, analytics, crash reporters, social sign-in, or payment modules are used.

5. Children

Since no personal information is collected, none is collected from children.

6. Your rights

There is no personal data held to access, correct, or delete. Game records stored on the device can be erased at any time by the player using the methods in section 2.

7. Changes

If this policy changes, the date above is updated and the change is recorded here.
