# 회사실무 → 스테이지 리서치

> 목적: 「출근 저지」에 넣을 스테이지 후보를 실제 한국 회사 실무에서 발굴한다.
> 원칙: **실무 이름 하나 = 규칙 하나.** 이름만 바꾸고 웨이브 표만 바꾼 건 스테이지가 아니라 스킨이다.
> 작성: 2026-08 / 근거는 각 항목에 표기

---

## 0. 이 문서의 판정 기준

지금 게임에 스테이지가 4개 있고, 각각 **다른 질문**을 던진다.

| 스테이지 | 플레이어에게 묻는 것 |
|---|---|
| 출근 저지 | 화력을 **어떤 순서로** 세울까 |
| 점심시간 외주납품 | 전선을 **얼마나 넓게** 펼까 |
| 회식 저지 | **속도**를 어떻게 감당할까 |
| 고객사 점검 | 보스에 화력을 **어떻게 집중**할까 |

새 스테이지는 **5번째 질문**을 가져와야 한다. 못 가져오면 넣지 않는다.
아래 후보는 전부 이 기준으로 ○/△/✗ 판정했다.

## 1. 업무보고 축 — 이건 스테이지가 아니라 **구조**다

### 핵심 발견

일일 / 주간 / 월간 / 분기 / 반기 / 연간을 **스테이지 6개로 만들면 실패한다.**
6번 반복되는 같은 게임이 되기 때문이다. 그런데 이 목록에는 게임 구조가 하나 숨어 있다.

**보고는 중첩된다. 일일 5개가 모여 주간 1개가 되고, 주간 4개가 모여 월간 1개가 된다.**

이건 레인 디펜스에 없던 메타 구조다.

### 제안: 「보고 부채(負債)」 시스템 — 캠페인 모드

```
일일보고 ×5  ─┐
              ├─→ 주간보고  ×4 ─┐
              │                  ├─→ 월간보고 ×3 ─→ 분기보고 ─→ … ─→ 사업계획
```

규칙:
- **일일보고 스테이지는 짧다** (40~50초). 하루치다.
- 놓친 일일보고 1건 = **주간보고 보스 HP +15%**. 놓친 건 사라지지 않는다. 쌓인다.
- 주간보고에서 놓친 건 다시 월간으로 넘어간다.
- 완벽하게 막으면 상위 보고가 **약해진다.** 대충 막으면 눈덩이가 된다.

→ 플레이어에게 묻는 5번째 질문: **"지금 한 번 더 버틸까, 다음을 위해 여기서 손절할까"**
   이건 레인 디펜스에 없는 질문이다. ○ **최우선 추천**

### 근거 (실무가 실제로 그렇다)

- 직장인은 하루 평균 **5시간 12분**을 보고서 작성에 쓴다. 8시간 근무의 **65%**.
  보고서 작성 빈도는 주 1–2회가 52.7%, "수시로"가 31.4%. ([사람인 조사](https://www.saramin.co.kr/zf_user/help/live/view?idx=108415&listType=news))
- 보고서 스트레스 원인 **1위(47%)가 "갑자기 시키는 경우가 많아서"**.
  3위(35.7%) "잦은 보고서 작성으로 정작 업무 할 시간이 없어서". ([같은 조사](https://www.saramin.co.kr/zf_user/help/live/view?idx=108415&listType=news))
  → **게임 규칙으로 직역 가능**: 예고 없이 끼어드는 웨이브 = 「지시 웨이브」.
     웨이브 예고선에 안 뜬다. 그냥 나온다. 이게 47%의 스트레스다.
- 자기가 쓴 보고서가 중요하다고 답한 사람은 **48.6%뿐**. 절반이 무의미하다고 느낀다.
  → 승리 메시지 톤의 근거: "보고는 반려됐습니다. 아무도 읽지 않았습니다."

## 2. 월말결산 — 승리 조건을 뒤집는 스테이지

### 왜 특별한가
지금까지 4스테이지는 전부 **"버텨라"** 다. 월말결산은 **"쳐내라"** 다.
시간이 내 편이 아니라 **적**이 되는 첫 스테이지.

### 제안 규칙: 마감 시계
- 화면 상단에 **마감 게이지**. 시간이 아니라 **처리 건수**로 승리한다.
- 목표: 90초 안에 전표 N건 처리. 못 채우면 **시간이 다 돼도 패배.**
- 적(전표)은 공격력이 약하다. 대신 **자리에 도달해도 죽지 않고 그냥 미처리로 남는다.**
  → 처음으로 "적을 통과시켜도 되는" 스테이지. 대신 카운터가 안 오른다.
- 후반 20초에 **가산세 압박**: 남은 미처리 건수만큼 화면이 붉어지고 적 속도 +40%.

→ 5번째 질문: **"막을까, 처리할까"** — 방어와 처리량이 처음으로 충돌한다. ○ **추천**

### 근거 (실제 마감일이 게임 규칙이 된다)
- **전자세금계산서: 공급시기가 속한 달의 다음 달 10일까지 발급.**
  10일이 토·공휴일이면 다음 영업일. 법인은 발행 의무. ([국세청](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2463&cntntsId=7789))
  → **"D-10" 이라는 실존하는 카운트다운.** 그대로 HUD에 박으면 된다.
- 지연발급·미발급 가산세, 매입세액 불공제 ([자비스](https://help.jobis.co/hc/ko/articles/115006067268))
  → 미처리 1건당 페널티의 실무적 근거.
- 부가세: 법인은 **연 4회**(1·4·7·10월 25일 전후) 신고. 2026년 1기 확정신고는 7월 27일.
  ([비즈파트너스](https://www.limnpartners.co.kr/notice/87), [볼타](https://bolta.io/insight/vat-filing-period-2026-guide))
  → 분기보고 스테이지와 캘린더가 겹친다. 캠페인 달력에 그대로 쓸 수 있다.

## 3. 다음해 사업계획보고 — 최종보스, 그리고 **이길 수 없는 보스**

### 왜 최종보스인가
사용자 표현대로 "최대난제". 그런데 게임적으로 진짜 특별한 이유가 따로 있다.

**사업계획은 잘 막을수록 불리해진다.** 올해 실적이 좋으면 내년 목표가 올라간다.

### 제안 규칙: 상향 조정
- 보스를 한 번 격퇴할 때마다 **다음 보스의 목표치가 올라간다.**
  격퇴 1회 → "올해 잘했네, 내년 **20% 더**" → 보스 HP ×1.2, 웨이브 밀도 ×1.15
- **완전 승리가 없다.** 언젠가는 뚫린다.
- 점수는 **몇 차수까지 버텼는가**. 리더보드가 여기서 나온다.
- 최종 화면: "3차 상향까지 방어. 목표는 4차로 재수립되었습니다."

→ 5번째 질문: **"언제까지 잘할 수 있나"** — 엔드리스 모드의 서사적 정당화. ○ **추천 (최종 스테이지)**

### 근거
- 연간 사업계획은 신년도 목표·전략, **부서별 업무목표, 매출계획**을 포함하고,
  1~12월 월별 목표/실적/달성률 + 분기 합계로 구성된다.
  ([비즈폼](https://m.bizforms.co.kr/magazine/view.asp?number=56104), [중기부 사업계획서 예시](https://www.mss.go.kr/common/board/Download.do?bcIdx=1000973&cbIdx=266&streFileNm=213f0b04-7030-4efa-805d-b2e6168f22ad.pdf))
  → 보스키(ESC) 화면을 **"2027_사업계획_v14_최종_최종.xlsx"** 로 바꾸면 그 자체가 개그.
- 탑다운 목표 하달 구조 = 위에서 숫자가 내려오고 부서가 쪼개 받는다.
  → 「목표 하달」 웨이브: 화면 위에서 아래로 숫자가 떨어져 5개 줄에 배분된다.

## 4. **이 회사 실무** 축 — 레포에서 캐낸 것

> `modules/pipeline.py`, `modules/supplier_mgr.py`, `MG커머스_사용가이드.txt` 기준.
> 앰지커머스의 실제 파이프라인: **제품발굴 → 1688 공급사 탐색 → 샘플 → 배대지 →
> 한국 도착 → 품질검수 → 본발주 → 배송 → 쿠팡 입고 → 런칭** (10단계)

이 축이 제일 신선하다. **레인 디펜스에서 본 적 없는 규칙이 여기서 3개 나온다.**

### 4-1. 통관 보류 ○ **강력 추천**
KC인증 대상 전기용품은 **통관 전에** 모델별 안전인증을 받아야 하고,
UNIPASS로 적합성평가확인서·요건확인서를 받아야 수입신고가 된다.
([safetykorea](https://www.safetykorea.kr/policy/targetsSafetyCert), [찾기쉬운 생활법령정보](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1504&ccfNo=2&cciNo=2&cnpClsNo=2))

**규칙:** 적이 화면 중앙 「세관 라인」에서 **멈춘다**(보류). 공격도 안 한다.
거기 쌓인다. 플레이어가 **서류 유닛(요건확인서)** 을 그 줄에 놓아야 풀린다.
안 풀면 계속 쌓이고, 한계를 넘으면 **한꺼번에 터진다.**

→ **적을 죽이는 게 아니라 통과시켜야 하는** 첫 규칙. 방향이 완전히 뒤집힌다.

### 4-2. 반품 ○ **강력 추천**
로켓그로스 반품: 단순변심은 구매자 부담, **상품 하자는 셀러 부담 + 보상 검토.**
반품 회수·재입고 요금은 현재 무료지만 부과 예정.
([리터니즈](https://returneeds.com/blog/online-seller-guide/2024-%EC%BF%A0%ED%8C%A1-%EB%A1%9C%EC%BC%93%EA%B7%B8%EB%A1%9C%EC%8A%A4-%EC%88%98%EC%88%98%EB%A3%8C%EB%8A%94-%EC%9E%85%EC%A0%90-%EB%B0%98%ED%92%88-%EB%85%B8%ED%95%98%EC%9A%B0-%EC%B4%9D%EC%A0%95/), [윈들리](https://www.windly.cc/blog/all-about-coupang-rocketgrowth))

**규칙:** 처리한 적의 일부가 **되살아나서 다시 온다.** HP는 절반, 속도는 1.5배.
「처리 완료」가 완료가 아니다.
→ 플레이어가 처음으로 **자기가 이긴 것을 다시 상대한다.** 심리적으로 가장 지치는 규칙.
   (실무 감정을 가장 정확히 옮긴 항목)

### 4-3. 입고 반려 △ **조건부**
로켓그로스는 표준 바코드 부착, 박스 외부 부착 서류 + 내부 동봉 서류를 빠짐없이
챙기지 않으면 센터에서 **반송**된다. ([장사왕](https://www.sellerking.io/blog/%EC%BF%A0%ED%8C%A1-%EB%A1%9C%EC%BC%93%EA%B7%B8%EB%A1%9C%EC%8A%A4-%EC%B5%9C%EC%8B%A0-%EC%9E%85%EA%B3%A0-%EA%B0%80%EC%9D%B4%EB%93%9C-1-57667))

**규칙:** 유닛을 놓을 때 **순서·조합 조건**이 붙는다. 조건 안 맞으면 설치 실패 + 자원 반환 없음.
→ 재밌지만 **짜증날 위험이 크다.** 4-1과 규칙이 비슷해서 둘 중 하나만.

### 4-4. 환율 △
`modules/exchange_rate.py` — CNY→KRW 실시간 조회로 마진 계산.
**규칙:** 자원(커피) 획득량이 스테이지 내내 ±40% 실시간 변동. 그래프가 HUD에 뜬다.
→ 좋은 **모디파이어**지만 스테이지 하나를 지탱할 만큼 크진 않다. 다른 스테이지 위에 얹자.

### 4-5. MOQ (최소주문수량) △
**규칙:** 유닛을 1개씩 못 놓는다. **한 번에 3개 단위**로만 놓인다.
→ 신선하지만 조작이 답답해진다. 특정 스테이지 한정 제약으로만.

## 5. 나머지 후보 — 빠른 판정

| 실무 | 5번째 질문이 있나 | 판정 |
|---|---|---|
| **감사자료 제출** | 지정된 **순서대로만** 처리 가능. 순서 틀리면 무효 | ○ 규칙 있음 |
| **ISO / 고객사 심사** | **부적합 1건 = 즉시 패배.** 완전 무실점 요구 | ○ 규칙 있음 (하드모드) |
| **재고 실사** | 화면이 어두워지고, **센 것만 보인다** (안개) | ○ 규칙 있음 |
| **인사평가 시즌** | 상대평가 — **동료 줄을 희생시켜야 내 줄이 산다** | ○ 규칙 있음 (윤리적으로 셈) |
| **연말정산** | 서류 수집 미니게임 | △ 레인 디펜스와 안 맞음 |
| **주간 회의** | 그냥 웨이브 | ✗ 스킨 |
| **워크숍/MT** | 그냥 웨이브 | ✗ 스킨 |
| **안전점검/중대재해** | 고객사 점검과 규칙 중복 | ✗ 중복 |
| **경조사** | 자원 소모 이벤트 | △ 모디파이어로만 |

## 6. 결론 — 넣을 순서

**1순위 (규칙이 확실히 새롭다)**
1. **월말결산** — 승리 조건 반전 (버티기 → 처리량). 제일 빨리 만들 수 있다.
2. **반품** — 이긴 적이 되살아난다. 코드 변경 최소, 체감 최대.
3. **통관 보류** — 죽이는 게 아니라 통과시킨다.

**2순위 (구조 작업)**
4. **보고 부채 캠페인** — 일일/주간/월간/분기 중첩. 게임 전체 구조가 바뀌므로 위 3개 뒤에.
5. **다음해 사업계획보고** — 상향 조정 엔드리스. 캠페인의 종착역.

**모디파이어로 얹을 것**
- 지시 웨이브 (예고 없이 끼어듦) ← 스트레스 원인 1위(47%)의 직역
- 환율 변동 (자원 획득량 실시간 요동)

**넣지 말 것**
- 보고 주기 6개를 스테이지 6개로 만드는 것 ← 같은 게임 6번

## 7. 부수 정리

- 보스키(ESC) 위장 화면을 실제 업무에 맞추면 개그가 산다.
  현재: 생산실적 집계 / 중간고사 오답노트
  추가 후보: **`2027_사업계획_v14_최종_최종_진짜최종.xlsx`**, `수입원가_계산_마진표.xlsx`
- 현재 보스키의 공정명(전처리/노광/에칭/전해/검사/출하)은 도금·PCB 공정이라
  이 회사(수입·유통) 실무와 안 맞는다. **수입 원가표**로 바꾸는 게 맞다.
