# 직장인 스트레스 해소 게임 — 기획 메모

> 상태: 아이디어 단계 (구현 전)
> 최초 작성: 2026-08-22 / 최종 갱신: 2026-08-22 (v2 — 저지 모드로 방향 전환)
> 목적: 잊어버리지 않도록 기록. MG Commerce 코드와는 무관한 별도 프로젝트.

---

## 1. 한 줄 요약

**상사를 출근 못 하게, 고객사를 점검 못 오게 막는 게임.**
직급·부서마다 다른 상대를 방해 카드로 지연시켜 정시(9시)에 도착하지 못하게 만든다.

---

## 2. 방향 전환 — v1(핵앤슬래시) → v2(저지)

처음 아이디어는 핵앤슬래시(적을 때려부수기)였으나, **"출근 저지 / 점검 저지"** 가
훨씬 나은 축이라고 판단해 메인 방향을 바꾼다.

### 왜 저지가 더 나은가
1. **공감 정확도**: 직장인의 진짜 판타지는 폭력이 아니라 "오늘 팀장 연차였으면",
   "점검 취소됐으면"이다.
2. **리스크 소멸**: 사람을 해치는 게 아니라 지연시키는 것 → 폭력성 0.
   명예훼손·표현수위·연령등급 문제가 통째로 사라진다.
3. **플레이 환경 적합**: 실시간 반사신경이 필요 없어 **회사 PC에서 조용히** 할 수 있다.
   이 게임의 실제 플레이 장소가 사무실이라는 걸 생각하면 이게 결정적이다.
4. **직급/부서 시스템이 그대로 들어맞는다** (아래 4번).

### v1 액션 모드는 버리지 않고 이렇게 재활용
- 저지 **성공** → 평화로운 하루 (승리)
- 저지 **실패** → 상사가 결국 출근함 → 사무실 스테이지로 넘어가 **뱀서라이크 액션 모드**
- 즉 "막으면 전략, 못 막으면 액션". 두 모드가 서사적으로 자연스럽게 연결된다.
- **단, MVP에는 저지 모드만.** 액션 모드는 재미 검증 후.

## 3. 코어 루프 — 출근 저지

상대의 이동 경로:

```
집 → 지하철/도로 → 회사 로비 → 엘리베이터 → 자리
```

플레이어는 경로 각 구간에 **방해 카드**를 배치한다.
제한 시간(09:00)까지 자리에 앉히지 못하면 승리.

### 방해 카드 예시
| 카드 | 효과 |
|------|------|
| 지하철 신호 고장 | 지하철 구간 지연 (차량 이용자에게 무효) |
| 교통 체증 / 주차 만차 | 도로 구간 지연 (차량 이용자 전용) |
| 엘리베이터 점검중 팻말 | 로비→자리 지연 |
| 타 부서 회의 소집 | 경로에서 아예 빼돌림 |
| 카톡 폭탄 | 이동 속도 감소 |
| 커피 쏟기 | 세탁/정리로 지연 |
| 상위 임원 호출 | 강력. 임원급에게 통하는 유일한 수단 |
| 골프 약속 | 차장급 즉시 이탈 |
| 재택 전환 공지 | 개발 부서 무력화 |

---

## 4. 직급 × 부서 시스템 (게임의 뼈대)

단순한 살 붙이기가 아니라 **난이도 티어(직급) × 속성 저항(부서)** 정식 시스템으로 설계.

### 직급 = 난이도 티어
| 직급 | 특성 |
|------|------|
| 인턴 | 방해 1개면 끝. 튜토리얼 |
| 사원 | 지각해도 크게 상관 안 함 |
| 대리 | 성실. 지하철 지연에 저항 |
| 과장 | 차 끌고 옴 → 지하철 방해 무효, 교통체증·주차로 막아야 함 |
| 차장 | **약점: 골프 약속** — 걸면 아예 안 옴 |
| 부장 | 일찍 출근 → 시작 시간이 30분 빠름 (방해 배치 시간 부족) |
| 임원 | 기사 딸린 차. 대부분 무효. 유일한 약점은 상위 임원 호출 |

### 부서 = 속성 저항
| 부서 | 특성 |
|------|------|
| 영업 | 외근 걸면 쉽게 빠짐 (가장 약함) |
| 개발 | 재택 공지에 즉시 이탈 |
| 생산 | 현장이라 무슨 수를 써도 옴 (가장 강함) |
| 인사 | 방해 수단 자체를 "규정 위반"으로 무효화 (카운터) |
| 재무 | 법인카드 정지 등 돈 관련 방해에만 반응 |
| 품질 | 점검 스테이지에서 등장. 서류로 막아야 함 |

> 조합이 곧 퍼즐이 된다. 예) "생산부 과장" = 차로 오고 무조건 출근 → 거의 최악 난이도.
> "영업부 대리" = 외근 한 장이면 끝.

---

## 5. 보스 = 고객사 점검

품질감사·현장실사를 오는 고객사 점검단이 스테이지 보스.

- 점검단이 **여러 명이고 각각 직급이 다름** → 동시에 전부 막아야 함
- 전용 방해: 도로 공사, 담당 휴가, "서류 이미 보냈다"고 우기기, 일정 다음 주로 미루기
- **최종 목표 = 점검 무한 연기.** 클리어 조건이 "격파"가 아니라 "연기 성공"인 게
  이 게임에서 가장 웃긴 지점이고 핵심 아이덴티티다.

---

## 6. 개인화 훅 (유지)

시작 화면 **"오늘 누구 때문에 힘드셨나요?"** → 직급·부서 선택 + 한 줄 입력.
입력한 문장이 그 판 상대의 말풍선이 되고, 저지 성공 시 그 말풍선이 사라진다.

> v1의 훅을 저지 모드에 맞게 변형. 여전히 이 게임의 유일한 진짜 차별점.

## 7. 표현·법적 리스크

### 7-1. 실존 인물·회사 절대 금지
- 실제 고객사명·협력사명·상사 이름 그대로 쓰면 명예훼손·모욕 리스크.
- 전부 가상 이름으로: (주)갑을산업, 흥한테크, 대박물산 등.
- 특정 인물을 알아볼 수 있는 조합(외모+말버릇+직책) 금지.
- 실무하며 만들면 실제 거래처가 떠오를 수밖에 없다. **이름은 무조건 세탁.**

### 7-2. 저지 모드는 폭력 리스크 없음
- 해치는 게 아니라 지연시키는 것이므로 v1의 유혈 표현 문제가 원천 소멸.
- (액션 모드를 나중에 붙일 경우에만) 쓰러진 적은 피가 아니라 서류·포스트잇으로 흩어지게.

### 7-3. 게임 "복제"에 대한 정확한 선
"요즘 복제해서 유사하게 만든다"는 반은 맞고 반은 위험하다.

**괜찮은 것 — 장르·규칙 차용**
- 뱀서라이크, 소울라이크, 배틀로얄, 타워디펜스 전부 그렇게 생긴 장르. 문제 없음.

**절대 안 되는 것**
- 스프라이트·음악·UI 등 리소스를 그대로 가져오기
- 코드 디컴파일·이식
- 이름/로고를 헷갈리게 짓기 (상표 문제)

**⚠️ 한국 특유의 함정**
- 2019년 대법원 **팜히어로사가 판결**: *게임 규칙 하나하나는 아이디어라 보호되지 않지만,*
  *규칙들의 선택·배열·조합이 창작적 개성을 가지면 저작물로 보호된다*고 판단.
- 즉 **특정 게임 하나를 통째로 유사하게 베끼면 한국에서는 진다.**
  "유사하게 만들더만"이 걸리는 지점이 정확히 여기.
- 안전한 길: **장르 문법만 가져오고 소재·조합은 직접 설계.**
  직급/부서/점검 테마는 어느 게임에도 없다 → 오히려 원본이 될 수 있는 조합.

**에셋**: 직접 제작하거나 CC0 라이선스만 사용. 출처·라이선스를 파일로 기록해둘 것.

### 7-4. 사내 플레이 대응
- 회사 PC에서 할 게임 → **보스키 필수.** ESC = 즉시 엑셀 화면 전환.
- 이 기능 자체가 최고의 밈 포인트가 된다.

## 8. 기술 스택

- **웹 브라우저 + JS.** 설치 없이 링크만 보내면 됨 = 확산력.
- 저지 모드는 실시간 액션이 아니라 **경로 + 타이머 + 카드 배치** 구조라
  Phaser 없이 순수 DOM/Canvas로도 충분. (액션 모드 붙일 때 Phaser 3 도입)
- 유니티는 오버스펙. 2D 도트.
- **별도 리포지토리 권장** — MG Commerce 배포에 영향 없게.

## 9. MVP 범위 — 2주

**이것만 만들고, 재미없으면 접는다.**

- [ ] 출근 저지 1스테이지 (단일 경로: 집→지하철→로비→엘베→자리)
- [ ] 방해 카드 5종
- [ ] 상대 직급 3종 (대리 / 과장 / 부장) × 부서 2종 (영업 / 생산)
- [ ] 09:00 타이머 + 승패 판정
- [ ] "오늘 누구 때문에 힘드셨나요?" 입력 → 상대 말풍선
- [ ] 재시작

**하지 말 것**
- 스토리·세계관 문서부터 쓰기 (재미 검증 후에 붙인다)
- 액션 모드 동시 개발
- 직급 7종 × 부서 6종 전부 구현 (조합 폭발 → MVP에선 3×2)

## 10. 확산

- 무료 웹 → 링크 공유. 직장인 커뮤니티에서 자연 확산.
- 랭킹은 개인이 아니라 **"부서별"** 로 — 공유 동기가 생긴다.
- 수익화는 나중. 먼저 퍼지는지부터 확인.
